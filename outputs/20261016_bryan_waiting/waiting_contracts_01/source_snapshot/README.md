# Bryan：途中待機・契約形態・既知活動の取消

この実験は、前回の長い教育滞在を生んだ「途中待機なし」を緩めて再計算する。教育終了とCampus出発を別の変数にし、教育後とCampus買物後の待機を許す。前回の実行記録は上書きしない。

実行前に固定した追加仮定と比較条件は [settings_contract.md](settings_contract.md)。掲載人物・係数の出典は [前回の出典監査](../minimal_contract/source_provenance.md)を参照。時間窓、OD、V2G契約、取消確率、待機費用は本実験の仮定であり、Swiss MTMCで観測・推定されたものではない。

## 何を比較するか

- A：D=4時間の固定整数LP双対を使った外挿。
- B：参照点の共通の活動・場所選択を固定し、取消後の時刻と待機を再最適化。
- C：全シナリオに共通の予定買物場所も最適化。

同額の参照解ではShopping Aを優先する。無料待機ではShopping Bも同額になるため、その場所を固定した場合の感度も保存する。Aは別の実行可能な活動スケジュールを作らない。

契約履行は「確実履行」「教育取消時の自動解除」「放電イベントのみ」を比較する。支払は、解除時も保持する加入固定額と、実放電量単価を区別する。全契約で期待補償、放電量、イベント供給確率、シナリオ別経路を記録し、供給の減少を含む比較を補償だけで順位付けしない。

## 一律pの情報構造と解釈

主実験 `uniform_activity` は、教育・Shopping A・Shopping Bがそれぞれ独立に同じ発生確率pで実現し、自宅は確実とする。pは取消確率ではない。8状態を列挙し、確率0の状態は制約から除く。

前日に加入・契約・予定買物場所を決め、06:00に実現状態が分かる。前日の予定場所、最初の出発07:00、残存活動の所要時間と相対順序を維持する。追加するのはCampusおよびDowntownでの途中待機であり、実現後に別の買物場所を選び直すことは許さない。教育が消えても買物が残る場合、早い到着後に長い待機が生じるのは、この共通出発制約による。原稿自体は変更しない。

`education_cancel`、`shopping_cancel`は原因を切り分ける補助実験で、以前の出発調整を許す仕様と取消確率の表記を使う。主図・主表はこの補助群と混ぜず、uniform_activityから作る。

自動解除は、教育取消によって必ず発動し、その状態の指令放電量を0に固定する。Shopping BでCampusに居ても任意の追加放電は行わない。各状態の放電量は活動選択に依存しないため、この例に限って必要期待補償を期待放電量で割ると実績単価の閾値になる。ゼロ供給・ゼロ負担では単価は意味を持たず、ゼロ供給・正の負担は有限単価では補償できない。選択的な解除、電力供給の内生選択、リスク回避、未知活動の到着、日中の緊急離脱は対象にしない。

## 再現

Pythonの依存関係は [既存のrequirements.txt](../minimal_contract/requirements.txt)と共通。未使用のrunディレクトリを指定し、設定・結果・ソルバー状態・ソース・検証・概要・考察をまとめて保存する。

```sh
python experiments/bryan_waiting/run.py --output outputs/new_run_id/waiting_contracts_01
python experiments/bryan_waiting/plot.py --run outputs/new_run_id/waiting_contracts_01
```

図表と日本語の結論は `outputs/20261016_bryan_waiting/report_ja.md` にまとめる。


数値処理は結果・ソース・検証記録を保存し、作図処理はPNG/PDFを作る。各runのoverview/discussionと日本語レポートは、この実行結果を読んで作成した考察記録である。
