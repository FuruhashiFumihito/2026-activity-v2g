# 契約価値・条件付き影価格・活動取消・SOCの数値実験

この実験は、会話で承認された「実行可能集合→価値関数→補償変分→条件付きLP感度」の理論を、指定した縮約モデルで検証する。既存の最小実験を再実行したうえで、活動取消とSOC保証が補償額・履行・活動選択を変える条件を調べる。原稿の全定式化、実際の契約受諾、福島の母集団への妥当性を検証したものとはしない。

## 実行

`experiments/minimal_contract/requirements.txt` の依存環境を使い、ルートから実行する。

```sh
python -m unittest discover -s experiments/theory_contract -p 'test_*.py'
python experiments/theory_contract/run.py --output outputs/NEW_UNIQUE_RUN_ID
```

既存の出力先は上書きしない。`settings.json` に全条件を先に保存し、各サブ実験に設定、原始求解記録、CSV、ソースのスナップショット、overview、discussionを保存する。原始記録は損失のないgzip圧縮JSONL。結果を変更せず図表を再生成するには `python experiments/theory_contract/report.py OUTPUT_DIRECTORY` を使う。

## 検証する問いと証拠

| ID | 検証する問い | 最も強い反論 | 比較・判定 |
|---|---|---|---|
| C1 | 固定整数LPの双対は同じ領域の補償変化に一致するか | 符号・効用尺度・基底切替の混同 | 参照点左右の有限差分、別定式化LP、解析折れ点列挙。許容差2e-7、差分傾き2e-5 |
| C2 | 連続的な制約切替と活動変更を分けて説明できるか | 全ての差を整数性や「活動喪失」に帰している | A=参照接線、B=活動固定LP、C=全MILP。Bが有限なら C-A=(B-A)-(B-C)。切替なし・連続切替・不連続断念を保持 |
| C3 | 取消の効果は接続機会・契約履行条件で変わるか | 活動・報酬・供給電力量の違いが原因 | 同じ活動・移動で設備アクセスだけを0/1にし、取消確率×必要接続時間×hard/softを全組合せ。正味補償と実接続・不足・履行確率を測る |
| C4 | SOC保証の拘束・実行不能境界を説明できるか | SOCは後から描いただけで選択に影響しない | SOC保証を変え、共通の事前充電、費用、全イベントの残量、到着時保証、充電上限、実行不能をLP/MILP・解析条件で照合 |

ソルバーが正常終了したことだけでは判定しない。全条件について、別の経路LP2本、解析的な折れ点評価、実スケジュールのSOC・時間・効用再計算と照合する。Bが実行不能なら有限の差の分解は報告しない。

## 理論とモデルの境界

原稿の全MILPを実装したという主張はしない。既存の掲載人物Bryanの縮約例は、公開入力と追加仮定を記録した `../minimal_contract/source_provenance.md` を引き継ぐ。新しい取消・SOC実験の数値は全て設計値で、効用を円相当に正規化する。BryanのCHFと混ぜない。

新モデルの共通計画は、勤務終了時刻 `w`、任意運動への参加 `g`、15–16時の事前充電 `c`。既知の予定1件は事前には組み込み必須で、実施 `xi=1` / 取消 `xi=0` が確率的に決まる。取消後はその予定を除く以外に、所要時間・順序・最初の出発・活動内の接続計画を変えない。勤務は9時からで、最早終了17時。運動の開始は `w+.25+.75*xi`、所要1時間、希望18時、最終開始18時30分。全実施の事前計画も維持するので、`g=1`なら常に`w<=17.5`である。取消確率1でもこの名目計画条件は除かない。

加入時は16–17時に6kWを放電する固定指令があり、全実現状態で供給は6kWh。接続義務は16–21時内の累積D時間で、実績は `w-16+0.5*xi*access`。予定場所のアクセスだけを変える対照により、取消の移動短縮効果と接続機会消失を切り分ける。hardでは全支持状態で不足0。softでは不足1時間につき2400の精算を払い、両仕様は同じ信頼性を約束する契約ではない。

充電前に勤務へ到着した残量は34kWh。勤務内の事前充電は6kWの固定入力に接続する長さに対応し、量 `c` は0–6kWh。放電後は `28+c`。予定場所では往路0.25kWhを消費するため、保証は `27.75+c` にもかかる。接続保証は活動到着時にも適用する。物理下限12kWh、容量60kWh、初期と日末36kWh、効率1。日末充電は6kWで、仕事場60/家庭30の充電単価と全方式に同じ通過電力量費2を課す。

追加の加入固定補償は求解中0とし、加入・非加入の期待費用差を符号付き機会費用C、その正の部分を必要補償とする。指定報酬での受諾はこのモデル内の無差別条件から計算し、実測受諾率とは呼ばない。通常充電アクセスは非加入にも残す。

未知の緊急活動の到着、事後の自由な活動再選択、解除権、電力網均衡、外的な推定精度、スケーラビリティは対象外。補助整数は不要なので、新モデルのB対Cは単一の活動参加選択の効果として解釈できる。

## 事前に導ける境界

- hardかつ取消状態が支持に含まれる場合、運動を維持して完全履行する上限はD=1.5h。アクセスあり・取消確率0なら接続0.5hを予定場所で補い、D=2hまで維持可能。
- soft、アクセスあり、D=1.5h、非拘束SOCでは、運動を維持した勤務延長の限界費用は`1800-900p`、取消時の不足精算の期待限界額は`2400p`。一致するp=6/11の前後を指定した。これはリスク回避ではなく、期待効用と有限精算による境界。
- SOC保証はアクセスなしで28kWh、アクセスありで27.75kWhを超えると事前充電が必要。後者の保証が33.75kWhを超えると、6kWhの事前充電上限により実行不能。全方式で34kWh超は到着時保証にも違反する。

これらの式から予想した境界と、実際のMILP/LPの一致を検査する。連続な切替や効果がない条件もそのまま保存する。
