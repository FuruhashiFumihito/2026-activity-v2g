\section{Model Formulation}
\label{sec:model_formulation}

% M01: 対象と構造型モデルを用いる理由
本研究では，車両から系統への給電（vehicle-to-grid; V2G）契約の接続・履行条件が，個人の活動スケジューリングと契約参加に与える影響を評価する枠組みを構築する．
活動の実施場所や時間を変更できる範囲を，移動と充放電の制約を満たすスケジュールの集合として表し，契約による集合の変化と効用の変化を対応づける．
このため，活動への参加，順序，開始時刻及び所要時間を，効用と制約から同時に導く構造型の活動スケジューリングモデルを用いる．
分析対象は電気自動車（electric vehicle; EV）を用いる個人の一日とし，契約条件及び事業者の充放電指令を所与とした利用者の選択を扱う．

% M02: 基礎モデル，拡張及び本節の構成
提案モデルは，\citet{wang2025joint}による活動・充電の同時選択モデルに，\citet{gan2013stochastic}のStochastic Preplanned Household Activity Pattern Problem with Uncertain Activity Participation（SHAPP）に基づく活動取消の表現と，V2G契約の接続条件及び精算を導入する．
活動の実施・取消が判明する前の共通計画と，取消後に実現する活動列を区別し，二段階の混合整数線形計画（mixed-integer linear programming; MILP）として記述する．
以下では，基礎となる活動モデル，活動参加の不確実性と効用，決定変数，活動・充放電・契約の制約，及び契約制約の価値を評価する分析方針の順に説明する．

\subsection{OASIS型の定式化}
\label{subsec:oasis_formulation}

% M03: 活動候補とdawn/dusk
\citet{pougala2023oasis}のOptimisation-based Activity Scheduling with Integrated Simultaneous choice dimensions（OASIS）では，一日のスケジュールを，自宅で始まり自宅で終わる活動列として表す．
計画期間を$[0,T]$，活動候補集合を$A$とし，始端と終端の自宅活動をそれぞれ$\mathrm{dawn}$及び$\mathrm{dusk}$とする．
各候補は活動種別，場所及び次の活動への移動手段によって区別され，参加，順序，開始時刻及び所要時間を同時に選択する．
本研究では移動手段をEVに固定し，候補$a$の場所を$\ell_a$，開始時刻を$x_a$，所要時間を$\tau_a$と記す．
両自宅活動は必ず活動列に含め，出発前及び帰宅後の滞在時間を一日の時間配分に含める．

% M04: OASISの基礎効用
活動スケジュールの基礎効用は，活動参加の効用，希望する開始時刻及び所要時間からの逸脱に伴う不効用，並びに活動間の移動に伴う不効用から構成する．
早い開始と遅い開始，短い滞在と長い滞在をそれぞれ区別し，対応する逸脱量に非正の係数を与える．
この表現により，ある活動の時間を確保するために別の活動を移動・短縮する場合の効用変化を評価できる．
望ましい時刻や時間長は選好の基準であり，営業時間等が定める実行可能時間窓とは区別する．

% M05: 活動列の実行可能性
活動列の実行可能性は，一日の時間予算，選択した活動への流入・流出，活動間の時刻連続及び活動固有の時間窓によって定める．
選択された直後リンクでは，前の活動の終了時刻に移動時間を加えた時刻を，次の活動の開始時刻と一致させる．
同じ活動機会の場所等の代替候補は高々一つ選び，非参加候補の所要時間とリンクをゼロにする．
これらの条件の下で活動効用を最大化することにより，活動参加と時間配分の相互依存をスケジュール全体として表す．

\subsubsection{\citet{wang2025joint}による活動スケジューリングフレームワーク}

% M06: Jointで同時に選択する活動と充電
\citet{wang2025joint}は，OASISに充電方式，充電時間，充電費用及びバッテリー充電状態（state of charge; SOC）を導入し，活動計画と充電行動を同時に決定する．
活動場所での充電と充電専用サービスステーションへの訪問を候補に含め，活動効用に充電開始の不便さ，充電量の便益，充電費用及び低SOCの不効用を組み合わせる．
本研究ではこの同時選択の構造を引き継ぎ，利用者が活動に付随する設備接続を選び，接続中の事業者指令に応じて充放電する場合へ拡張する．

% M07: 活動取消の不確実性と二段階モデル
V2G契約選択における利用者選好についてのいくつかの研究を鑑みるに\citep{parsons2014willingness}、活動取消の不確実性は，利用者の行動に大きな影響を与えることが示されている．
本研究では，利用者は(a) 活動の不確実性下で契約加入と活動計画を事前に選択し，(b) 取消情報を得た後に実現可能な活動列の下で接続・充放電を実行する，二段階の意思決定を行うと仮定する．
それぞれを"pre-planning"と"post-realization"の段階と呼び、index $p$と$r$を用いて，事前計画とシナリオ別の実現を区別する．

% M12: 第1段階変数 
第1段階の変数は，契約加入，事前の活動参加・順序・開始時刻・所要時間，及び活動内の接続方式・開始オフセット・接続時間である．
加入を$Y_N$，活動参加を$\omega_a^p$，直後リンクを$z_{ab}^p$，活動の開始時刻と所要時間を$x_a^p,\tau_a^p$とする．
接続参加を$\phi_a^p$，方式$m$の選択を$\varphi_{a,m}^p$，活動開始からの接続オフセットと接続時間を$o_{a,m}^p,d_{a,m}^p$とする．
これらは取消情報を得る前に決まり，全シナリオに共通である．
順序補助変数$h_a$は事前活動列の前後関係を表し，活動開始時刻とは区別する．

% M13: 実現変数と状態・精算の補助変数
第2段階では，実現した活動と直後リンク，活動開始時刻，接続の絶対開始・終了時刻，実充放電量，SOC，及び契約精算をシナリオ別に表す．
取消活動の活動時間と接続をゼロにし，残存活動では接続参加・方式・オフセット・接続時間を事前値から維持する．
活動開始の絶対時刻がずれるため，接続区間と事業者指令の重なり，実充放電量及びSOCは実現時刻から再計算する．
これに加えて，希望時刻・所要時間からの逸脱，低SOC不足，契約接続時間，未達量，報酬額及び線形化に必要な補助変数を用いる．
実現変数を導入することと，それらを自由に選び直せることは区別する．

% M14: 変数領域と入力の区別
加入，活動参加，直後リンク，接続参加，方式選択及び達成認定は二値変数とし，時刻，時間長，電力量及びSOCは連続変数とする．
順序を表す$h_a$は連続の補助変数とし，正の部分や条件付き支払の線形化には追加の二値変数を用いる．
活動実現値，シナリオ確率，移動時間・距離，設備アクセス，契約パラメータ及び事業者の充放電指令は入力である．
時間はhour，電力量はkWh，金額は円，SOCは電池容量に対する比率で表し，系統側の電力量と電池側の残量変化を区別する．

\subsection{V2Gサービスを考慮した拡張済み制約条件}
\label{subsec:constraints_of_the_v2g_contract}

\subsubsection{活動の連続・順序・時間制約}

% M15: 時間予算，経路及び活動時間窓
活動制約は，$\mathrm{dawn}$から$\mathrm{dusk}$までの一つの活動列と，その列に整合する時間配分を定める．
一日の時間予算には各活動の所要時間を一度ずつ加え，選択リンクの移動時間と合わせて$T$に一致させる．
各参加活動に必要な流入・流出を課し，自己リンク，始端への流入及び終端からの流出を除く．
順序補助変数による制約で循環を除き，ゼロ時間の活動を含む場合も活動列を維持する．
非参加活動の時刻・所要時間をゼロとし，参加活動には最小所要時間及び実行可能時間窓を適用する．

% M16: 取消後の短絡と維持する時間配分
取消後の経路には，残存活動を元の相対順序で結ぶ直後リンクを与える．
例えば，事前活動列$a\to b\to c$で$b$が取り消された場合，実現列では$a\to c$を許し，事前の直後リンクをそのまま固定しない．
残存する通常活動の所要時間と最初の自宅出発時刻は維持し，途中待機を加えずに移動と活動の連続条件から実現開始時刻を定める．
帰宅時刻が早まった場合の残余時間は，終端自宅活動$\mathrm{dusk}$の所要時間が吸収する．
この取消ルールにより，活動の削除が後続活動の時刻と接続可能時間帯をどのように変えるかを表す．

% M17: 硬い時間窓と選好・軟らかい時間窓
活動の時間窓は，事前計画では厳守し，実現後についても物理的に厳守すべき窓を維持する．
取消後の早い開始や遅い終了を費用として扱える活動を指定する場合に限り，窓からの逸脱量を導入して実現効用から控除する．
開始時刻の希望値からの逸脱と，開始・終了の実行可能時間窓からの逸脱は別の量であり，両方を評価する場合には同じ負担の二重計上を確認する．
時間窓を費用に置き換えることは実行可能集合を変更するため，対象活動と係数を明示し，全ての窓を厳守する設定も残す．

\subsubsection{SOC，充電，放電制約}

% M18: 正味SOC収支と経路に沿った移動可能性
SOC収支は，接続中の充放電と活動間の走行消費を，実現した活動列に沿ってつなぐ．
系統側の充電量に充電効率を掛け，放電量を放電効率で除した電池側の取出量を差し引き，電池容量で割って活動中の正味SOC変化を求める．
次の活動へ移動する直前には走行に必要な残量を確保し，選択リンクでは出発時SOCから当該移動の消費量を差し引いた値を次の到着時SOCに一致させる．
日初SOCと，終端自宅での充放電を含む日末SOC下限は，全契約及び非加入時で共通に与える．
V2G接続による正味SOC変化を常にゼロとする簡略化は，本基本モデルでは置かない．

% M19: 中間SOC，保証及び全支持シナリオの物理実行可能性
過充電と過放電を防ぐため，活動の到着・出発時だけでなく，充放電指令の各区間境界における累積SOCを容量内に制限する．
一つの活動で高々一方式を選び，各入力区間で指令が一定かつ充電又は放電の一方向である条件の下では，境界の残量から区間内の残量も確認できる．
契約に最低SOCや出発時残量の追加保証，電池側の通過電力量の上限を含める場合には，対応する制約を別に指定する．
最低SOC保証を用いる仕様では到着時から下限を課し，保証未満で到着してから回復充電を行う仕様とは区別する．
物理制約は正の確率を持つ全シナリオで満たし，実行不能なシナリオを除いて確率を付け直さない．
契約未達のペナルティは物理制約を緩和せず，どの事前計画にも実行可能な第2段階が存在するとは仮定しない．

% M20: 接続区間，固定指令及び時間別精算
設備接続は実施活動の滞在内に収め，設備アクセスのない方式と，非加入者によるV2G方式の選択を禁止する．
通常充電は非加入でも利用でき，充電専用サービスステーションでは滞在全体を接続に用いる．
契約，指令電力及び精算単価は計画時に既知とし，これらが一定となる共通時間区間と，連続時刻で選ぶ接続区間との重なりから実電力量を計算する．
充電と放電を同時に指令しない入力を与え，通常方式の放電指令はゼロとする．
接続中の待機は接続時間に含めるが電力量には加えず，充電費用は各料金区間の実輸入量に基づいて計上する．
電池利用費は電池側の充放電通過量に比例させ，通常充電及び非加入時にも共通の仕様で適用する．

\subsubsection{V2G契約条件}

% M21: 義務条件と報酬対象の分離
V2G契約は，接続・履行条件と報酬の算定基準を別々に指定する．
全時間の接続を求める固定窓を$W_{F,k}$，累積接続時間を計上する窓と必要時間を$W_{L,k},D_k$，各報酬の対象窓を$W_{R,h,k}$とする．
窓$W$内のV2G接続時間$L^s(W)$には待機時間も含め，固定窓の全接続と，窓内で分割可能な累積時間を区別する．
報酬を指定時間帯だけに適用することは，その時間帯への接続義務を意味しない．
条件を設定しない価格型，固定窓又は累積時間の達成型，及び両条件を併用する型を，同じ接続集計に基づいて表す．

% M22: 契約精算と達成認定の意味
契約支払は，加入固定額，条件達成時の固定額，実接続時間に比例する報酬及び実放電量に比例する報酬から構成し，充電割引は対象実輸入量の費用に反映する．
達成条件を満たした場合だけ支払う項には達成認定変数を用い，条件なしの実績報酬とは区別する．
認定変数が1なら接続条件を満たす制約を課すが，この含意だけで達成との同値が成立するとはしない．
達成による純便益が正の場合に利用者の最大化で認定される精算構造を用い，その限界便益がゼロの場合の達成実績は実接続時間から判定する．
この認定の扱いは利用者の効用最大化に対応するものであり，事業者の支払最小化問題へそのまま転用しない．

% M23: 未達許容と完全履行の比較条件
未達負担は，接続条件を満たさない場合の固定負担と，固定窓又は累積時間に対する不足量に比例する負担によって表す．
有限の負担を設定する場合，事前に加入した利用者が取消後に未達となることを許し，その支払と効用を評価する．
全ての支持シナリオで完全履行を求める比較設定では，これとは別に加入時の全接続条件を実現後の制約として課す．
加入は取消前に決めるため，シナリオを見て加入を取り消す選択は与えない．
対象は単日の固定窓及び分割可能な累積時間とし，連続接続の要求，月間達成日数及び緊急離脱権を扱うには別の契約属性が必要である．

\subsection{最適化フレームワーク}
\label{subsec:optimization_framework}

% M24: MILPとしての求解方針と成立条件
所与の契約と区分一定の指令の下で，有限シナリオの期待実現効用を最大化する決定論的等価MILPを構成する．
活動の実現値と指令電力は定数であり，接続区間の重なり，正の部分及び二値変数で条件づける精算を，有限上限と補助変数で線形に表す．
接続時刻を指令区間の端点へ丸める必要はないが，指令電力も利用者の決定変数に変更する場合には同じ線形表現は成り立たない．
まず整数変数を含む問題を解き，契約ごとの期待効用と実現スケジュールを比較する方針とする．
以下の感度・価値分析はこの定式化に対する分析計画であり，数値実装又は性能検証の結果を示すものではない．

% M25: 固定整数解に条件づけたKKTとshadow price
シャドープライスは，得られた整数解を固定した連続問題に対して評価する．
活動参加・順序・方式・加入に加え，区間との重なりや達成精算を表す全ての補助二値変数も固定すると，残る問題は線形計画（linear programming; LP）となる．
実行可能で有限な最適値を持つ場合に，Karush--Kuhn--Tucker（KKT）条件の主・双対実行可能性，停留条件及び相補性から，接続時間やSOC等の制約の双対変数を調べる．
双対変数による感度は，固定した整数構造の下で該当する連続問題の感度関係が保たれる範囲に限られ，活動列等の切替を含むMILP全体の限界価値とは区別する．
退化による双対解の非一意性や，契約窓の変更が制約右辺以外にも及ぶことも確認する．

% M26: 柔軟性の価値とoption valueの定義方針
活動の柔軟性を失う価値は，接続・履行条件を課した場合と，対象条件を緩和した場合について，整数選択を含む問題をそれぞれ解き直した最適期待効用の差として評価する方針とする．
この比較は，局所的な双対変数だけでは捉えられない活動参加や順序の切替も含む．
その差をoption valueと呼ぶ場合には，何の選択権を維持する価値かを特定し，緩和する条件，維持する報酬・指令及び比較時の情報を定義する必要がある．
本草稿では契約制約の緩和価値を検討対象とし，完全情報を得る価値や加入を延期する価値とは区別する．
必要補償額は，加入が実行可能で有限の補償が存在する場合に，加入と非加入の最適期待効用が等しくなる報酬水準から評価する方針とする．
加入自体が実行不能な場合や，達成報酬を増やしても受給条件を満たせない場合には，有限の必要補償額が得られるとはしない．
効用差を円に換算する場合には金銭限界効用と報酬の受給条件を明示する．

% M27: 比較の公平性と仮説の位置づけ
契約比較では，活動候補，嗜好の抽出値，活動実現分布，設備アクセス，初期・終端SOC，電池利用条件及び事業者の指令方針を共通とし，期待支払予算を揃える．
加入の有無，活動計画の変更，期待効用，接続条件の達成及び必要補償額を調べ，報酬の違いと履行条件の違いを分けて評価する．
活動予定の不確実性が強いほど契約制約の負担や必要補償額が増すという関係は，この比較によって検討すべき研究仮説である．
その方向をモデルの一般的性質又は既存の参加意向調査から確定した結果としては仮定しない．
