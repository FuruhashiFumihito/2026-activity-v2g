# 最小契約実験：掲載人物Bryanと合成例の検算

このフォルダは、固定接続義務の変更に対する補償額を、A（参照点のLP双対による線形外挿）、B（参照点の全整数選択を固定したLP再最適化）、C（整数選択も含むMILP再最適化）で比較する、決定論的な初回診断実験です。Aは別の活動スケジュールを生成しません。

## 収録例と位置付け

- **Bryan（最初の掲載人物例）**：Wang, Pougala and Hillel (2025), *Joint modelling of electric vehicle charging and daily activity scheduling*, TR-D 147, 104911, doi:10.1016/j.trd.2025.104911 のTables 3–4、A.1、A.3にある人物・希望時刻・係数を使用。V2G・時間窓・OD・SOC境界等を明示的に追加した縮約例であり、原論文の完全再現や実測日誌の復元ではありません。
- **合成例（手計算照合）**：会話で事前に指定した勤務と任意運動の4候補。円相当に正規化した診断用係数を使い、事前の手計算表を独立に検算します。BryanのCHFとは混在させません。

元論文の省略・曖昧さを含む出典の境界は `source_provenance.md`、個別の追加仮定は各runの `config.json` と `overview.md` に記録します。これらの例は活動取消、緊急時の解除権、推定精度、人口への外的妥当性を検証しません。

## 実行

Python 3.13で専用の仮想環境を作り、`requirements.txt`の依存ライブラリをインストールしてください。リポジトリルートから、未使用の出力先を指定して実行します。

```sh
python experiments/minimal_contract/bryan.py --output outputs/new_run_id/bryan_01
python experiments/minimal_contract/synthetic.py --output outputs/new_run_id/synthetic_01
```

各実験は既存runを上書きしません。ソルバーはSciPy経由のHiGHSです。設定、結果、ソルバー状態、手計算と独立パターン列挙との照合、図、overview/discussionを同じrunディレクトリに保存します。A/B/Cは同じ入力・同じ日初日末SOC・同じ放電量で比較します。実行不能なBは欠損のまま保持し、ゼロや大きな罰金へ置き換えません。

## 初回run

`outputs/20261016_minimal_contract/bryan_01/` と `outputs/20261016_minimal_contract/synthetic_02/`。個別の結果と検証状態は各runを参照してください。図のAは参照点の局所価格の外挿であり、適用範囲外では実行可能な活動計画を意味しません。

## 検証する問い

| 問い | 主な反論 | 対応する比較・証拠 |
|---|---|---|
| 局所価格は近傍の補償変化を表すか | 符号や金銭換算が誤っている | 参照LPの双対と左右1分の有限差分・手計算 |
| 有限変更で何が変わるか | 連続制約の切替と離散活動変更を混同している | A対Bと、B対C、活動場所・参加・時刻の記録 |
| 契約受諾判定へ影響するか | 値の差だけで意思決定上の意味がない | 全再最適化による補償額を基準に、近似による閾値判定との差を示す |
| 実装は指定設定を解いているか | 手計算を出力しただけではないか | 実際のMILPとLPの状態・残差・独立パターン列挙・手計算の照合 |

結果に合わせて境界を作り直さず、Bryanでジャンプが出なければそのまま記録します。合成例の既知の断念境界が、掲載人物でも存在するという主張はしません。

日本語の図表付き結果は `outputs/20261016_minimal_contract/report_ja.md` を参照してください。初回 `synthetic_01` は保持し、SOCを計算で検証した `synthetic_02` を最終参照とします。
